# Design records

`specs/` holds the designs agreed before a feature was built and `plans/` the step-by-step plans used
to build them. They are kept as a record of why things are the way they are, and are not updated
afterwards: where they differ from the code, the code and the main [README](../../README.md) are
authoritative.
